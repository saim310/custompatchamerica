## Quote workflow

All page order buttons open the same native dialog, with browser focus containment, Escape dismissal, focus restoration and scroll locking. The inline form and dialog use the same form and `/api/quotes` handler. The handler validates both fields and actual file signatures, limits the streamed request size, rejects cross-origin requests, and returns success only after a private record is written or a configured receiver accepts the request. Artwork is optional; accepted formats are PNG, JPEG, WebP and PDF, at most 3 MB. Company and message are optional.

Development saves actual quote records and base64 artwork to ignored `.data/quotes/<receipt-id>.json`. This is private local storage, not email delivery. It does not notify anyone. Remove development records when no longer needed.

Production deliberately returns HTTP 503 until one of these is configured:

- `QUOTE_WEBHOOK_URL`: your HTTPS quote receiver. Receives multipart data with `request` (JSON: id, createdAt, source and validated fields) and optional `artwork` file. `QUOTE_WEBHOOK_TOKEN` is sent as a Bearer token. The receiver must durably accept requests before returning a 2xx status. Requests include an `Idempotency-Key` for receiver deduplication. There is no automatic retry after an ambiguous timeout.
- `QUOTE_STORAGE_DIR`: an absolute, private directory on persistent storage. Do not use a serverless ephemeral disk or the public directory. Arrange staff access, notifications and retention for this storage; no mail is sent automatically.

Set `QUOTE_SITE_ORIGIN` to the public origin if a reverse proxy changes the origin seen by Next.js. Set `QUOTE_TRUST_PROXY=true` only when the proxy overwrites `X-Forwarded-For`. The in-memory abuse guard is per instance; use hosting-level request limits for a multi-instance production deployment. Uploaded files are stored privately, never executed or publicly served; apply the receiving system’s malware screening before staff open attachments.

No contact phone/email was present in the source project. Set `CONTACT_PHONE` and `CONTACT_EMAIL` in the environment to render real contact links (rebuild the statically generated page after changing them). `.env.example` documents all options. Do not commit credentials or customer records.
